
# Introducción al lenguaje PHP

Si quieres seguir practicando PHP, puedes hacer los siguientes ejercicios de ampliación en la misma rama de git. Para ello, simplemente crea una carpeta llamada `ejer_ampliacion` dentro de la carpeta `ut2-ejercicios` y nombra cada ejercicio con `ejer1.php`, `ejer2.php`, etc. 

## Ejercicio 1

Crea un fichero solo con código HTML (es decir, un fichero `.html`) y otro fichero en PHP (es decir, un fichero `.php`) con el código necesario para escribir en la pantalla del navegador:

**Hola mundo!**

El texto se tiene que visualizar grande; se puede utilizar la etiqueta HTML `<h1>`. Incluye comentarios en ambos ficheros.

## Ejercicio 2

Escribe un programa que cada vez que se ejecute muestre dos números al azar entre 0 y 100 y que escriba su media aritmética. Puedes utilizar la función `rand()`.

## Ejercicio 3

Escribe un programa que cada vez que se ejecute muestre dos números al azar, uno de ellos que represente el peso de una persona (entre 50 y 100 kilos) y el otro la altura (entre 1.50 y 2.00 metros), y que escriba el IMC correspondiente, redondeado con un decimal.

Se recuerda que el IMC se calcula con la fórmula:

\[
IMC = \frac{\text{peso (kg)}}{\text{altura (m)}^2}
\]

## Ejercicio 4

Escribe un programa que cada vez que se ejecute muestre tres números al azar entre 0 y 150 que correspondan a una cantidad de horas, minutos y segundos, y que escriba su valor en segundos.

## Ejercicio 5

Escribe un programa que cada vez que se ejecute muestre una cantidad de segundos al azar entre 0 y 10000 y que escriba su valor en horas, minutos y segundos.

## Ejercicio 6

Escribe un programa que cada vez que se ejecute muestre dos números que representan dos tiradas de dados entre 1 y 6, al azar, e indique el resultado total (la suma de los dos dados).

## Ejercicio 7

Define tres variables enteras y asígnales un valor aleatorio entre 1 y 10. Luego crea un string (cadena de caracteres) que una dichas variables e imprímelo por pantalla.

Utiliza la coma (`,`) para unirlas.

## Ejercicio 8

Concatena dos cadenas cualesquiera con el operador punto (`.`) y muestra el resultado.

## Ejercicio 9

Escribe el código PHP necesario para definir una variable de cada uno de los siguientes tipos (`integer`, `double`, `string` y `boolean`), asignarles valores o datos a todas ellas y visualizarlas (hay que visualizar tanto el nombre de la variable como su valor) en el navegador, de forma que aparezcan una por cada línea.

Por ejemplo, si una de las variables es `$num=3`, en el navegador debería visualizarse:

`$num=3`

Imprime una cadena entre comillas dobles que incluya comillas dobles.
