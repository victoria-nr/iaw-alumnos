# Implantación de Aplicaciones Web (ASIR)

Bienvenido al sitio de materiales del módulo **Implantación de Aplicaciones Web**.

Este material está organizado de forma progresiva. Cada unidad puede incluir:

- teoría
- ejemplos
- ejercicios
- prácticas
- soluciones, cuando el profesor decida publicarlas.

## Objetivo del curso

El objetivo del módulo es que el alumnado sea capaz de **preparar entornos de implantación web reproducibles**, desarrollar pequeñas aplicaciones web en servidor, conectarlas con bases de datos y, en la parte final del curso, implantar, administrar y adaptar gestores de contenidos.

Se trabajará con un enfoque técnico, progresivo y verificable para que cada estudiante llegue a poder:

- montar y documentar entornos de trabajo y despliegue;
- distinguir con criterio el papel del servidor web, el runtime de aplicación y la base de datos;
- desarrollar aplicaciones PHP sencillas con formularios, sesiones y acceso a datos;
- implantar y mantener CMS con criterios básicos de seguridad y administración;
- justificar sus decisiones técnicas y comprobar que lo entregado funciona de verdad.

## Metodología

La metodología del módulo combina explicación breve, demostración guiada y trabajo práctico continuo.

- Cada unidad contiene una sección de apuntes de teoría en donde irán apareciendo mini ejercicios y ejercicios finales de consolidación que el alumno deberá realizar y documentar. También se realizarán cuestionarios para evaluar el nivel de compresión y aplicabilidad de todo lo aprendido.
- Cada unidad incluirá además una o varias prácticas más amplias, planteadas como proyectos con su propia documentación y, cuando haga falta, los archivos correspondientes para asegurar su reproducibilidad.
- Se pedirá documentación técnica mínima y útil: comandos usados, decisiones tomadas, incidencias encontradas y forma de comprobar que el resultado funciona.
- La evaluación no se basará solo en el resultado final, sino también en la capacidad de explicar, corregir y adaptar lo entregado.

## Entregas

Las entregas se organizarán en un **único repositorio privado de GitHub por alumno** para todo el módulo que contendrá de forma organizada todo el trabajo de cada unidad (ejercicios y prácticas). Por tanto, es imprescindible que el alumno tenga nociones básicas de Git/GitHub.

Dentro de ese repositorio:

- cada UT tendrá un `ejercicios.md` para recoger los mini ejercicios y ejercicios finales en Markdown;
- cada práctica se entregará como un proyecto independiente dentro de la carpeta de su unidad;
- las prácticas que requieran un entorno reproducible deberán incluir los archivos necesarios para arrancarlas y verificarlas;
- el profesor revisará ramas, commits, Pull Requests, documentación y evidencias de funcionamiento.


La guía detallada de trabajo está en [Entregas del curso](entregas.md) y en [Tutorial previo: Git y GitHub para tu repositorio de entregas](git-github-entregas.md).
