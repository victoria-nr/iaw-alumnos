    Práctica 1 · Preparación exacta del proyecto base de la UT1¶

    1. Qué vas a hacer¶

    En esta práctica vamos a preparar el proyecto base para la siguiente práctica. El proyecto se llamará ut1-entorno-web, que será la base de la práctica 2.

    El objetivo es crear toda la estructura del proyecto, convertirlo en repositorio Git y documentar de forma mínima y útil qué contiene y para qué servirá.

    2. Qué demuestra esta práctica¶

    Con esta práctica debes demostrar que sabes:

    • preparar un proyecto base;
    • verificar qué herramientas forman parte del entorno de trabajo;
    • iniciar y revisar un repositorio Git;
    • documentar el punto de partida del proyecto.

    Criterios del RA1 trabajados¶

    • CE1. Identificación del software necesario.
    • CE2. Identificación de tecnologías empleadas.
    • CE8. Uso de plataformas orientadas a prueba y desarrollo.
    • CE9. Documentación de procedimientos.

    3. Caso de trabajo¶

    Vas a crear un repositorio con estos elementos iniciales:

    ut1-entorno-web/
├── .env.example
├── compose.yaml
├── app/
│   └── index.php
├── nginx/
│   └── default.conf
└── sql/
    └── init.sql

    Tu tarea consiste en crear esta estructura de carpetas y ficheros, inicializar un repositori Git dejarlo listo para continuar con la práctica 2.

    4. Resultado exacto que debes obtener¶

    Al finalizar esta práctica, tu carpeta ut1-entorno-web debe incluir al menos:

    • la estructura anterior;
    • un repositorio Git inicializado;
    • un archivo README.md con el contenido indicado en esta práctica;
    • un archivo estado_entorno.txt con los comandos de comprobación indicados;
    • un commit con el mensaje exacto especificado.

    5. Tareas obligatorias¶

    Parte 1. Crear estructura y repositorio¶

    Crea la estructura de ficheros y carpetas. A continuación, entra en la carpeta principal e inicializa el repositorio Git.

    cd ut1-entorno-web
git init

    Parte 2. Crear el README.md¶

    Crea un archivo README.md con este contenido (debes rellenar donde corresponda):

    # UT1 · Proyecto base del entorno reproducible

## Objetivo
Preparar la base del proyecto de la UT1 para continuar con la práctica de despliegue reproducible.

## Archivos localizados
- compose.yaml
- .env.example
- app/index.php
- nginx/default.conf
- sql/init.sql

## Papel de cada herramienta en esta UT
- Git: (rellenar)
- Docker: (rellenar)
- Docker Compose: (rellenar)

## Estado final
Repositorio inicializado y proyecto listo para la práctica 2.

    Parte 3. Crear el archivo estado_entorno.txt¶

    Crea un archivo estado_entorno.txt con el resultado de ejecutar los siguientes comandos:

    git --version
docker --version
docker compose version
git status

    Parte 4. Revisar la estructura del proyecto¶

    Comprueba que en tu repositorio existen y se pueden localizar rápidamente estos archivos:

    • compose.yaml
    • .env.example
    • app/index.php
    • nginx/default.conf
    • sql/init.sql

    Parte 5. Registrar el estado inicial¶

    Ejecuta estos comandos:

    git add .
git commit -m "Prepara base del proyecto UT1"

    Si tu Git local no tiene configurado usuario y correo, configúralos antes del commit.

    6. Entrega¶

    La entrega de esta práctica consiste en publicar tu repositorio local en un repositorio remoto de GitHub.

    Paso 1. Crear el repositorio en GitHub¶

    Entra en tu cuenta de GitHub y crea un repositorio nuevo con estas condiciones:

    • nombre recomendado: ut1-entorno-web
    • visibilidad: la que indique el profesor
    • sin README, sin .gitignore y sin licencia inicial, para no mezclar archivos creados por GitHub con los de tu repositorio local

    Paso 2. Vincular el repositorio local con GitHub¶

    Cuando GitHub te muestre la URL del repositorio recién creado, ejecuta en la terminal de tu ordenador, dentro de ut1-entorno-web, estos comandos:

    git remote add origin URL_DE_TU_REPOSITORIO
git branch -M main
git push -u origin main

    Sustituye URL_DE_TU_REPOSITORIO por la URL real de tu repositorio. Por ejemplo:

    git remote add origin https://github.com/usuario/ut1-entorno-web.git

    Paso 3. Comprobar la entrega¶

    La entrega se considerará realizada cuando se cumpla todo esto:

    • el repositorio existe en GitHub;
    • contiene los archivos de la práctica;
    • se ve el commit Prepara base del proyecto UT1 en la rama principal.

    7. Criterios de éxito¶

    La práctica se considerará correcta si se cumple todo esto:

    • la estructura de carpetas coincide con la indicada;
    • el README.md contiene el texto pedido;
    • estado_entorno.txt contiene el resultado de los cuatro comandos exactos;
    • el proyecto está versionado con Git;
    • el commit inicial usa el mensaje exacto solicitado.
    • se ha subido el repositorio a Github

    8. Checklist rápido del alumno¶

    • He creado ut1-entorno-web con la estructura de ficheros y carpetas.
    • He inicializado Git dentro de esa carpeta.
    • He creado README.md con el contenido exacto pedido.
    • He creado estado_entorno.txt con los comandos exactos.
    • He localizado compose.yaml, .env.example, app/index.php, nginx/default.conf y sql/init.sql.
    • He hecho el commit Prepara base del proyecto UT1.
    • He subido el repositorio a Github
