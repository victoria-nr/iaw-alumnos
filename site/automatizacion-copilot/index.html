    Automatización del flujo de UTs con GitHub Copilot¶

    Este repositorio incluye una capa de automatización para generar nuevas unidades de trabajo con VS Code + GitHub Copilot sin perder trazabilidad curricular ni coherencia con la estructura del módulo.

    Idea general¶

    La generación de nuevas UTs no debe partir directamente de prompts sueltos ni de volver a leer cada vez la PD completa.

    El flujo recomendado es este:

    1. PD .docx como fuente original.
    2. Extracción a contexto normalizado en YAML y Markdown.
    3. Uso de docs/UT2 como molde formal.
    4. Generación y revisión con agentes, skills y prompts.
    5. Comprobación final en MkDocs.

    Qué encontrarás en el repositorio¶

    • curriculum/fuentes/: documento original de la programación didáctica.
    • curriculum/generado/: contexto normalizado del módulo y de cada UT.
    • .github/agents/: agentes especializados.
    • .github/skills/: skills reutilizables.
    • .github/prompts/: prompts reutilizables.
    • scripts/: automatizaciones auxiliares.

    Por qué este enfoque¶

    Porque así separas claramente tres capas distintas:

    • fuente curricular;
    • contexto procesable;
    • material docente final.

    Eso hace el trabajo más:

    • repetible;
    • trazable;
    • mantenible;
    • menos dependiente de un único prompt largo.

    Flujo práctico en VS Code¶

    1. Extraer la PD¶

    python scripts/extract_pd_context.py curriculum/fuentes/PC02.01-02R02_Prog_didactica_0376_IAW_26-27.docx curriculum/generado

    2. Validar la UT que quieres generar¶

    python scripts/validate_ut_context.py curriculum/generado/uts/UT4.contexto.yaml

    3. Generar la UT con Copilot¶

    Usa el prompt:

    /generar-ut-desde-contexto UT4

    O selecciona el agente Redactor UT y dale como contexto:

    • curriculum/generado/uts/UT4.contexto.yaml
    • docs/UT2/
    • la carpeta de destino

    4. Revisar el resultado¶

    Usa:

    /revisar-ut docs/UT4

    Recomendación final¶

    No uses el .docx como contexto principal en cada conversación. Úsalo como documento fuente y trabaja a diario con el contexto normalizado de curriculum/generado/.
