# IAW - Material para alumnado

Repositorio publico de apuntes, practicas y materiales de apoyo del modulo Implantacion de Aplicaciones Web.

## Web del curso

Este repositorio esta preparado para publicarse con MkDocs.

En local:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

## Uso por parte del alumnado

Clona el repositorio una vez:

```bash
git clone URL_DEL_REPOSITORIO
```

Y actualizalo cuando el profesor publique nuevo material:

```bash
git pull
```

No entregues practicas modificando este repositorio. Las entregas se haran en el espacio o repositorio que indique el profesor.
